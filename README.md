# Petit — Centro Polispecialistico dell'Età Evolutiva

Landing page per il centro Petit, accessibile su [www.centropetit.it](https://www.centropetit.it).

Sezioni: Home, Servizi, Attività, Contatti.

## Stack

Angular 21 (Standalone Components + Signals), TypeScript, SCSS, Vitest.

Deploy automatico su GitHub Pages all push su `main`.

## Sviluppo

```bash
npm run dev   # ng serve — avvia il server di sviluppo su http://localhost:4200
npm run build # ng build — build di produzione in dist/
npm run test  # ng test — esegue i test con Vitest
```
